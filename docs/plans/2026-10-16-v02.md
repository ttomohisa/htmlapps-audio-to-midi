# v0.2 implementation plan

Base: PR #1 head dc21f43; PR #1 is unmerged, so this milestone is a dependent Draft PR against feat/audio-midi-v01. Preserve the approved subtitle, canonical workspace frames and modal scroll lock.

## Outcome and scope

Make inferred mistakes inspectable by seeing the waveform and piano roll, selecting a note, and comparing original audio with a simple synthesizer. Implement ATM-025 through ATM-032. No recording, note editing, sensitivity controls or new third-party dependencies.

## Design

- Keep the original decoded AudioBuffer (native rate and channels) separate from 22,050 Hz model PCM. Do not alter or export original metadata.
- Use one Web Audio transport clock. Original and synth modes are mutually exclusive; pause/resume, stop and seek share the exact seconds timeline. Input replacement, reset and hidden/page-exit paths stop audio. Async resume is generation guarded.
- Render a read-only note view with seconds and MIDI pitch axes, a combined-channel waveform overview, synchronized playheads and horizontal zoom/scroll. Keep source note seconds unchanged. A nearby native note selector provides an accessible alternative to tapping short rectangles.
- Keep waveform, transport, piano roll and selection details together inside one canonical framed workspace. Use a dedicated scrolling piano viewport; responsive placement puts review before export on phones and prevents page-wide horizontal overflow at 320/360 px.
- Use short lookahead synth scheduling, quiet envelopes, and explicit node/context cleanup. No samples, sound fonts, CDN or network calls.

## Steps

1. Add and test pure timeline geometry/waveform helpers and a deterministic playback engine.
2. Build the bilingual, responsive review UI; integrate it with source generation, note results and lifecycle handling.
3. Update milestone copy, Help, build assembly and dependent-PR workflow targeting.
4. Run contracts/build/model tests; independent source review. Exercise actual file variants and ordinary HTTPS preview, then verify downloaded MIDI still matches the unchanged note data after zoom/selection/playback.
5. Capture actual desktop/320/360 px results and record exact CI evidence. Keep physical-device and audible-device gates explicitly unverified.
