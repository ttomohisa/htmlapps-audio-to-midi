# v0.3 recording and mobile workflow

Base: main a5aaffef9a314620047ca2c9b5fadab62ca4e8c7 (v0.2, PR #2 merged).

## Scope
- Explicit Record gesture requests audio-only microphone access. No prompt on initial load.
- Native MediaRecorder MIME capability checks, complete-Blob decode validation, Record / Stop / Listen / Discard, optional named recording download. No new dependencies.
- Feed recordings through the existing decode → mono/resample → explicit Analyze → model/MIDI path; never infer immediately after Stop.
- Meter has no speaker/destination connection. Stop/discard/error/hidden/pagehide release microphone tracks and transient graph/timers. Pending permission and stale callback generations are invalidated.
- Stop automatically at 59 seconds (a conservative margin below the 60-second decoded input cap) or the 50 MiB byte cap.
- Confirm losing a recording on replacement/reset, and confirm stopping an active recording when leaving its mobile page. Native unload warning is best effort only.
- Adapt canonical mobile-bottom-bar to Input / Notes / Export page tabs at <=600px with safe-area spacing, real disabled states and intact desktop panels/header/help.

## Verification plan
1. Deterministic recording lifecycle tests with fakes: denied/missing device, pending grant cancellation, error/track loss, final chunk ordering, repeated stop, caps, no monitoring connection, cleanup.
2. Existing 58 tests + shared input/MIDI invariants.
3. Actual Chromium virtual microphone with native MediaRecorder: choose supported MIME, record/stop/decode/play, no automatic inference, explicit model analysis, MIDI download/readback. No physical or user audio in test.
4. Both standalone variants offline; HTTPS preview then offline; refusal/unsupported fallback to file; recorded blob download/redecode; mobile 320/360/390 and short viewport tabs/modal locks.
5. Independent source review, standard build/integrity CI, normal PR preview, exact-head evidence.

Physical Windows/Android/iOS microphone permissions, speaker listening, touch and browser-specific file:// microphone availability remain manual gates. Do not claim them from virtual devices.

References: W3C MediaStream Recording https://www.w3.org/TR/mediastream-recording/ and Media Capture https://www.w3.org/TR/mediacapture-streams/ (read 2026-10-16).
