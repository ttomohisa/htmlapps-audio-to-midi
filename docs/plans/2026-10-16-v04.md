# v0.4 manual note editing

Base: merged main cc97e55 (PR #3); automatic Pages publication succeeded.

## Bounded design
- Keep immutable detected notes separate from a session-owned editable note list. Display, synth playback and MIDI consume the same current list.
- Single-note selection and adjacent touch-sized controls: add, delete, semitone steps, 0.05-second start/end steps, direct pitch name/MIDI and second inputs with explicit Apply.
- Validate finite 0 <= start < end <= clip duration, integer MIDI 0–127. Preserve overlapping notes and original precision; edits preserve detected/manual provenance.
- Deletion uses canonical Toast + Undo plus a persistent undo-deletion control. Full general Undo/Redo remains v0.5.
- Confirm unsaved edits before reanalysis, input/recording replacement and reset; cancelled dialogs retain the current session. Async confirmations capture the session generation/revision so stale responses cannot overwrite newer work.
- Download marks the exact current note fingerprint saved; future edits become unsaved again. Page close warning is best effort. No automatic persistence.
- No model, dependency, CSP, input limit or release-pipeline changes.

## Verification
Pure validation/state/pitch/deletion tests; browser file and recording regressions; real-model inference; edited MIDI independent readback; invalid fields, zero-note add/delete/undo, confirmation cancellation, bilingual 320/360/390 layouts, keyboard, offline normal/self-extract and HTTPS preview. Standard PowerShell checks/build and independent review before ready for review. Physical device gates remain explicit.
